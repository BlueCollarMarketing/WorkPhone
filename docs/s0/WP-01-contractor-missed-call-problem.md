## Purpose

Capture stakeholder notes on missed leads, after-hours calls, job-site noise, and trade jargon. Record problem framing for S0 evidence before OTS baseline runs.

## Stakeholder problem framing


| Theme                  | Notes                                                                                                    |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| Missed leads           | Calls go unanswered while crews are on jobs; callbacks often too late to win the estimate.               |
| After-hours / weekends | Inbound volume continues evenings and weekends; human coverage is inconsistent.                          |
| Job-site conditions    | Callers and staff often speak with background noise (tools, traffic, weather).                           |
| Trade jargon           | Callers use trade-specific terms (estimate vs emergency vs service call) that generic scripts mishandle. |
| Incomplete info        | Callers often omit address, urgency, or callback window; incomplete handoffs waste dispatch time.        |




## Current handling gaps (observed)

1. No reliable 24/7 answer path for small contractor businesses.
2. Messages / voicemail do not consistently capture service type, urgency, location, and callback number.
3. Generic answering behaviour does not reflect trade-specific intake needs.
4. Operators lack a short, actionable post-call summary tied to job context.



## S0 evidence use

This framing feeds:

- OTS insufficiency scripts (estimate, service, after-hours, incomplete, callback)
- Draft U1-U3 uncertainty statements
- BRD outline placeholders for telephony, dialogue, summaries, and concurrency
